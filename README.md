rbc — Telegram-бот для регистраций и рассылок

Проект: лёгкий Telegram-бот, используемый организаторами мероприятия (РБК) для сбора регистраций на ивенты, рассылки оповещений и хранения контактных данных участников в CSV.

## Ключевые возможности

- Регистрация пользователей через команды и диалоги в Telegram.
- Сбор email участников и сохранение данных в CSV (`data.csv`).
- Бэкап файла данных и отправка его на фиксированный Telegram-чат/пользователю.
- Проверка наличия пользователя в канале (через `get_chat_member`) перед регистрацией.
- Простые массовые рассылки по команде администратора.

## Стек и зависимости

- Python 3.8+ (рекомендуется)
- telebot (pyTelegramBotAPI)
- pandas

Зависимости перечислены в `requirements.txt`.

## Установка

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте виртуальное окружение и активируйте его:

```bash
python -m venv .venv
source .venv/bin/activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Переменные окружения и параметры

Проект ожидает наличия файла `param.py` (не в репозитории) с, как минимум, двумя переменными:

- `token` — токен Telegram-бота (строка)
- `check_name` — имя канала/чата без `@`, которое используется для проверки членства

Пример `param.py`:

```python
# param.py (пример, НЕ добавлять в репозиторий с реальным токеном)
token = "123456:ABC-DEF"
check_name = "biz_rbc_chat"
```

Дополнительно в коде используется константа `backup_id` — идентификатор чата/пользователя, куда отправляется CSV-резервная копия.

## Запуск

Запуск бота производится просто:

```bash
python bot.py
```

Бот запускает метод `bot.polling(none_stop=True)` и будет работать постоянно, пока не завершится процесс.

## Запуск тестов

В репозитории нет явных тестов; `test.py` содержит лишь минимальный код. Для добавления тестов рекомендуется использовать `pytest`.

Пример быстрой проверки кода (статическая проверка и запуск):

```bash
python -m pip install pytest
python -m pytest -q || true
```

## Важные нюансы и рекомендации по безопасности

- Никогда не коммитить `param.py` с реальным токеном в публичный репозиторий.
- Резервные копии (`data.csv`) отправляются по Telegram — убедитесь, что `backup_id` настроен корректно.
- Обработка ошибок и логирование в текущей версии минимальны — для продакшена рекомендуется добавить обработку исключений, персистентное хранилище (БД) и проверку прав доступа к рассылкам.
- Проверьте корректность типов при чтении CSV — код предполагает наличие определённых колонок.

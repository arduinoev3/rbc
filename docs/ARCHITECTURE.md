# Архитектура и важные детали

Проект — монофайл `bot.py` с минимальной логикой и CSV в качестве персистентного хранилища.

Компоненты:

- bot.py — обработчики команд и сообщений, логика регистрации и рассылки.
- data.csv — основной источник данных (создаётся и обновляется pandas).
- sorted/ — вспомогательные скрипты для парсинга и подготовки данных (`parse.py`, `chanel.txt`).
- bot.service — пример systemd-сервиса для автозапуска на Linux.

Рекомендации для улучшения:

1. Хранение токена: использовать секреты окружения или менеджер секретов (HashiCorp Vault, Azure Key Vault и т.п.).
2. Заменить CSV на БД (Postgres/SQLite) для конкурентного доступа и атомарных операций.
3. Добавить обработку ошибок и ретраи для операций Telegram API.
4. Вынести конфигурацию (backup_id, каналы, пороги) в отдельный файл/переменные окружения.
5. Добавить модульные тесты для логики парсинга и обновления CSV.

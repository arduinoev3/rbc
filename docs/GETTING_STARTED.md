# Быстрый старт

1. Клонируйте репозиторий:

```bash
git clone <repo-url>
cd rbc
```

2. Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Создайте `param.py` с токеном бота и именем канала (пример в README).

5. Запустите бота:

```bash
python bot.py
```

6. При первом запуске создастся `data.csv` с шаблонной записью.
